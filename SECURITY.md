# Security

## Reporting a security problem

Please do not post credentials, private microscopy data, or sensitive file paths in a public issue.

For a security problem that can be described safely, open a GitHub issue with the minimum details needed to reproduce it. For sensitive reports, contact the repository owner through the email address linked to the GitHub account.

## Scope

OpenGridSeg reads local TIFF files and writes local OME-TIFF, CSV, and JSON files. It does not require a network service or store credentials.
